Agregar productos con CSV

Carga un CSV alineado con el modelo actual de StockiAPP para crear o actualizar productos y sumar unidades según cantidad.

Regla de importación: por cada fila se crea o encuentra el producto por ID, se actualizan sus datos vigentes, incluida la locación y la talla cuando aplique, y se crean N unidades DISPONIBLE según cantidad. Si la línea no existe todavía en este tenant, StockiAPP la crea automáticamente antes de procesar las filas válidas.
