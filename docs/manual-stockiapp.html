¿Qué es StockiAPP?
Plataforma web + asistente Telegram — la misma base de datos, dos formas de acceder

StockiAPP está pensada para operar inventario, clientes, ventas, créditos, retomas, cambios y trazabilidad desde una misma interfaz. También concentra documentos operativos y puntos de impresión en el mismo sistema.

🖥️ Plataforma web

Acceso desde navegador, optimizada para tablet y escritorio. Concentra la visión completa: dashboard, inventario, clientes, ventas, créditos, facturas operativas, etiquetas, configuración e impresión. Ideal para gestión y supervisión.

📲 Asistente Telegram

Funciona directamente desde Telegram. Puedes escribirle o enviarle mensajes de voz — siempre responde por texto. Registra ventas, retomas, cambios y créditos, consulta clientes, y entrega reportes en tiempo real vía API sobre la misma base de datos.

💡 Todo lo que registres desde Telegram queda inmediatamente reflejado en la plataforma web, y viceversa. Siempre estás viendo los mismos datos.

Roles de usuario
Aplica igual en la web y en el bot

En la operación diaria hay dos roles principales: vendedor y administrador. El rol aplica en ambos accesos: lo que puede hacer un vendedor en la web es exactamente lo mismo que puede hacer en el bot. La plataforma también cuenta con un rol técnico de administración de empresas, usuarios y claves.

Inventario
Centro operativo — consulta, filtra y actúa
Plataforma web
Bot Telegram

El patrón se repite siempre: buscar → filtrar → abrir acción → confirmar. La vista está optimizada para operar sin perder contexto ni duplicar clientes.

Qué puedes hacer

  • Buscar por producto, filtrar por línea o estado
  • Editar un producto y ver el cambio en la misma tabla, sin recargar la pantalla
  • Duplicar un producto base con nuevo ID, SKU interno y unidades nuevas Solo admin
  • Abrir acciones rápidas: imprimir etiqueta, reservar, registrar daño, prestar producto, preparar retoma o ver historial
  • Iniciar ventas, cambios, retomas, créditos o ajustes de inventario desde el contexto correcto

Editar y duplicar productos

Editar producto
Abre Más acciones → Editar producto. Guarda nombre, línea, ubicación, precio, talla, retoma, owner y notas. La fila se actualiza sin perder filtros, búsqueda ni posición.
Duplicar producto Solo admin
Abre Más acciones → Duplicar producto. Revisa el nuevo ID generado, ajusta los datos y confirma. El duplicado crea SKU y unidades nuevas; nunca copia ventas, créditos, préstamos ni historial.
💡 El ID visible identifica el producto para la operación. El SKU interno se genera de forma independiente para mantener la trazabilidad.

Cómo leer la tabla sin perder tiempo

Prioriza: producto, línea, valor, estado y stock. Si ves un producto con crédito activo, retoma habilitada o stock en cero, la propia fila te da contexto antes de abrir otro módulo.

⚠️ Verifica nombre, SKU, línea, stock disponible y reglas activas antes de confirmar cualquier cambio.

Préstamos físicos
Entrega temporal de productos con retorno y trazabilidad

Usa este módulo cuando una unidad sale temporalmente del inventario y debe regresar. No registres un préstamo como venta: el préstamo conserva el vínculo con el producto, las unidades, el cliente y la fecha de retorno.

1
Inicia el préstamo Usa Nuevo Préstamo o abre Más acciones → Prestar producto desde Inventario.
2
Selecciona producto y cliente Elige las unidades disponibles, reutiliza el cliente existente y registra vencimiento, contacto y notas necesarias.
3
Confirma la salida El sistema cambia el estado de las unidades y deja el préstamo visible en el listado.
4
Cierra cuando regresen las unidades Abre el detalle en Préstamos de producto, revisa el retorno y confirma el cierre para devolver las unidades a la operación.
Antes de confirmar
Revisa producto, cantidad, cliente, fecha de retorno y observaciones. La operación queda auditada con el usuario que la ejecuta.
Si una unidad no regresa
No la marques como disponible manualmente. Revisa el detalle del préstamo y registra el estado real para conservar la trazabilidad.
🤝 El acceso a préstamos puede estar habilitado por configuración del negocio. Si no ves la acción, consulta al administrador.

El comprobante se genera dentro del mismo flujo. La factura operativa existe como respaldo secundario, pero no aparece como primera acción. El cierre real de la venta queda pensado para imprimir en formato térmico sin salir de la pantalla.

Créditos
Ventas a crédito, abonos y seguimiento de cartera
Plataforma web
Bot Telegram

Antes de abrir un crédito, busca y reutiliza al cliente existente. Así el historial de deuda, pagos, facturas y préstamos queda unido a una sola ficha.

Cliente
  • Nombre o documento
  • Teléfono
  • Ciudad si aplica
  • Se reutiliza el mismo customer_id
Tipos de crédito
  • Crédito de producto: venta a crédito con producto y stock
  • Préstamo de dinero: préstamo sin afectar inventario
  • Cuotas, valor, notas y estado quedan editables
  • El historial de pagos y cambios se conserva

Cómo entender el estado de un crédito

Un crédito útil muestra: cuántas cuotas van, cuántas faltan, cuál fue el último abono, cuándo ocurrió y si hubo cambios recientes en cuotas, valor o estado.

Registrar un abono

Antes de abonar, consulta el crédito correcto. Después registra el pago sobre ese registro y verifica que el número de cuota y el histórico queden coherentes.

Comprobante de pago

Después de registrar una cuota o abono puedes abrir su comprobante y ticket de pago. El documento conserva una copia de los datos del crédito y del cliente tal como estaban al momento del pago.

⚠️ Evita crear créditos con datos incompletos del deudor. Un crédito sin identificación clara complica cobro, seguimiento y búsqueda futura.

Retomas y cambios
Operaciones especiales con trazabilidad completa
Plataforma web
Bot Telegram

Retomas y cambios no son variaciones de una venta. Cada una tiene su propio contexto, su propio impacto en stock y su propia lectura futura.

🔄 Retoma

Se usa cuando recibes un equipo de un cliente. Puedes decidir si lo publicas al stock disponible o no. Registra: cantidad, valor recibido, estado y notas útiles.

↔️ Cambio

Se usa cuando sale un producto y entra otro. Mantiene trazabilidad sobre la persona, las cantidades y los productos afectados.

Antes de publicar una retoma al stock

Verifica: estado recibido, valor esperado, condición comercial del producto y si realmente debe volver a disponibilidad. No toda retoma debe publicarse de inmediato.

Antes de cerrar un cambio

⚠️ Confirma el producto saliente, el entrante, las cantidades y la persona del cambio. Un cambio mal registrado puede desordenar inventario y auditoría al mismo tiempo.

Registrar una retoma

Iniciar retoma
Quiero registrar una retoma de un iPhone 11
Retoma con estado
Voy a recibir un Samsung A52 en mal estado

El bot solicitará: estado del equipo (Nuevo, Usado, Dañado, Para repuestos u Otro), valor pagado al cliente, si se publica al stock y notas opcionales. Mostrará el precio de referencia de retoma antes de confirmar.

Configuración
Solo plataforma web · Solo administrador

Aquí defines el marco visible del negocio, no la operación diaria. Configurar bien evita fricción después y deja listos los formatos térmicos del negocio.

Catálogos de inventario

Líneas de negocio
Crea, renombra y activa o desactiva las líneas que aparecen al crear, editar, importar o duplicar productos. Un renombrado actualiza los productos asociados dentro del mismo negocio.
Ubicaciones
Define las ubicaciones físicas disponibles. Una ubicación activa aparece como selector en productos y puede dejarse vacía cuando no aplica.

Eliminar una línea o ubicación

1
Desactiva el valor Solo los valores inactivos pueden eliminarse. Las líneas y ubicaciones activas quedan protegidas para no romper productos existentes.
2
Elige Eliminar y reasigna Si hay productos asociados, selecciona una línea o ubicación activa de reemplazo. La reasignación es obligatoria antes de confirmar.
3
Confirma y revisa El cambio se ejecuta en una transacción y deja auditoría. Después revisa Inventario para comprobar los valores actualizados.

Impresión

Define una sola vez el ancho térmico por defecto de etiquetas, facturas operativas y ticket térmico. Así cada documento sale con el formato correcto sin repetir el ajuste en pantalla.

  • Etiquetas: 80 mm, 58 mm o 57 mm
  • Facturas operativas: ancho térmico configurado por negocio
  • Ticket térmico: usa el mismo preset del tenant

Operación general

  • Define líneas, ubicaciones y responsables antes de cargar productos masivamente
  • Revisa métodos de pago y movimientos activos — controla qué operaciones aparecen
  • Mantén consistencia visual: nombre, color y datos del negocio sin generar ruido
  • Si usas automatizaciones o carga masiva, valida primero líneas, ubicaciones y owners disponibles

Actualizar ubicaciones por CSV

Los administradores pueden cambiar la ubicación de varios productos desde Productos → Actualizar ubicación. La plantilla solo requiere las columnas id y location.

1
Prepara el archivo Usa el ID visible de cada producto y la nueva ubicación. Deja location vacía para dejar el producto sin ubicación. Una ubicación nueva se crea automáticamente; una ubicación inactiva debe activarse antes.
2
Valida antes de aplicar La pantalla muestra la ubicación actual, la nueva y las filas rechazadas. Los productos inexistentes o las ubicaciones inactivas deben corregirse.
3
Confirma y revisa La operación solo cambia la ubicación, no el stock ni los datos comerciales. Cada cambio queda en Auditoría.
⚙️ Si vas a usar automatizaciones o carga masiva, valida primero líneas, ubicaciones, owners y parámetros de impresión. Así reduces errores al crear productos.

Auditoría
Solo plataforma web — qué pasó, cuándo y quién lo hizo

La auditoría explica qué pasó. No es solo un historial para revisar tarde — te ayuda a reconstruir la secuencia de cualquier operación: evento, usuario, fecha y detalle operativo.

Inventario
Puedes identificar ajustes, ventas, retomas, préstamos, cambios, ediciones y duplicaciones de productos, incluido el producto origen.
Catálogos
Las reasignaciones y eliminaciones de líneas o ubicaciones quedan registradas junto con el usuario que las confirmó.

Cuándo entrar a auditoría

  • Cuando un número no cuadra
  • Cuando un stock cambió sin explicación aparente
  • Cuando necesitas confirmar qué usuario ejecutó una operación específica

Cómo leerla sin perder tiempo

Empieza por fecha, tipo de evento y usuario. Después entra al detalle solo de los eventos que realmente explican el cambio que estás investigando.

Integraciones
Conecta automatizaciones sin exponer la base de datos

StockiAPP puede conversar con automatizaciones usando la API interna para consultar inventario, ventas, créditos, retomas y configuraciones relevantes. Eso mantiene consistencia y evita atajos frágiles.

Qué suele consultar una integración

  • Inventario disponible
  • Ventas recientes o completas
  • Créditos y abonos
  • Líneas, ubicaciones y owners para validar carga de productos
  • Clientes, facturas y préstamos según permiso

Qué conviene evitar

⚠️ No dependas de hojas paralelas como fuente principal. No uses la base de datos directamente. No automatices sin validar catálogos o IDs previamente.
🔗 Si una automatización va a crear o actualizar datos, primero valida el contexto operativo: producto correcto, línea correcta, ubicación activa, owner correcto y operación habilitada.
🔐 Las API keys pertenecen a un tenant. No envíes tenant_id manualmente: el contexto se resuelve por la credencial autenticada. Consulta los contratos vigentes en docs/api.md.
🤖
Agente StockiAPP
Accede a toda la operación desde Telegram

StockiAPP también vive dentro de Telegram. El agente es un asistente que respeta el contrato API documentado (docs/api.md) y ofrece inventario, ventas, retomas, créditos, reportes y configuración sin entrar a la web.

¿Qué es el agente?

Puedes hablarle por texto, audio o enviar fotos de etiquetas con código de barras. Gestiona inventario, ventas, retomas, cambios, créditos y reportes directamente desde el chat.

Cómo comunicarte

  • Texto: escribe tu solicitud normalmente
  • Audio: manda una nota de voz
  • Foto: comparte la etiqueta del producto para venta rápida

Si el audio no se entiende, el agente te pedirá que repitas para no registrar datos errados.

Registrar crédito o préstamo
Recoge datos del cliente, cuotas, valor total e interés; calcula cuota automáticamente.

Pagos, abonos y edición

  • Registra abonos y cuotas por nombre o documento
  • Elige “Cuota” o “Abono” para diferenciar pagos
  • Admin puede editar créditos y estados (Activo, Suspendido, Cancelado, Completado)

Facturas y reportes

Genera factura luego de venta o crédito con los datos del cliente (nombre, documento, teléfono, ciudad). También puedes consultar facturas por cliente, documento o fechas.

Productos e inventario

Admin crea productos con línea, precio, stock inicial, ubicación y retoma. También puede ajustar stock, precio y cambiar el ID visible sin afectar el historial operativo.

Gráficas y reportes automáticos

Pide al agente gráficas por canal, semana o rango de fechas y las mostrará en el chat. El sistema envía también resúmenes diarios y quincenales a los administradores: ventas, retomas, abonos y los gráficos de evolución.

Acceso y consejos

Los nuevos usuarios escriben al bot de registro y esperan aprobación del admin. Recomendamos confirmar cada operación, hablar con naturalidad y dejar que el agente resuelva el canal y el vendedor automáticamente.

✅
Buenas prácticas
Hábitos simples que evitan errores grandes

La herramienta ya cuida varias reglas, pero una operación limpia depende también de cómo se usa.

🔍
Busca antes de crear
Evita duplicados y registros paralelos del mismo producto o crédito.
📝
Deja notas con contexto real
No llenes campos por llenar. Usa observaciones que ayuden después.
🎯
Cada operación en su módulo
No uses ventas para simular créditos, ni ajustes para esconder errores.
✅
Revisa antes de confirmar
Es el mejor momento para detectar errores pequeños antes de que se vuelvan históricos.
🧬
Duplica con intención
Usa Duplicar producto para una nueva referencia; no para continuar el historial del producto origen.

Específicas para el bot

  • Siempre confirma con SÍ — ninguna operación se registra sin tu aprobación
  • No necesitas buscar IDs ni precios — el bot los obtiene automáticamente
  • Si cometiste un error en un registro, comunícalo al administrador
  • Para créditos, ten a mano el documento y teléfono del deudor antes de iniciar
  • Puedes interrumpir cualquier proceso iniciando una nueva consulta

Para todo el equipo

  • Mantén líneas y ubicaciones activas solo cuando estén disponibles para la operación
💡 Si el equipo entero trabaja con la misma lógica de uso, StockiAPP se vuelve más rápida, más confiable y mucho más fácil de auditar.
🛟
Solución de problemas
Respuestas rápidas a situaciones frecuentes
StockiAPP no responde
Espera unos segundos y reintenta. Si persiste, avisa al administrador.
"No estás registrado" en el bot
Comunícate con el administrador para que te registre en el sistema. Solo el admin puede agregar usuarios.
No encuentra el producto
Prueba con el nombre simplificado. Ej: "iPhone 13" en lugar de "iPhone 13 Pro Max 256GB".
"Esa función es solo para administradores"
La función solicitada requiere rol admin. Consulta con tu encargado si necesitas esa operación.
"Ese movimiento no está habilitado"
El tipo de operación está desactivado en la configuración del sistema. Avisa al administrador.
Error al registrar una operación
StockiAPP indica el campo con error en lenguaje natural. Corrige el dato y confirma de nuevo.
Un número del dashboard no cuadra
Ve al módulo correspondiente y revisa la fuente del dato. Si persiste, entra a Auditoría para reconstruir la secuencia.
No aparece "Duplicar producto"
La acción solo está disponible para administradores y productos base. Los créditos y préstamos tienen sus propios flujos y no se duplican desde Inventario.
La fila desapareció después de editar
La edición conserva la búsqueda y filtros activos. Si el nuevo valor ya no coincide, la fila se oculta; limpia o ajusta los filtros para encontrarla.
No puedo eliminar una línea o ubicación
Debe estar inactiva y, si tiene productos asociados, necesitas escoger un valor activo de reemplazo. Las reasignaciones no pueden apuntar a otro tenant.
No puedo cerrar un préstamo físico
Abre el detalle del préstamo desde el listado, verifica el cliente y las unidades, y registra el estado real de retorno. No cambies el stock por fuera del flujo.
